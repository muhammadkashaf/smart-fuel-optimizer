# Smart Fuel Optimization and Resource Management System frontend

React + Vite client for the Smart Fuel Optimization and Resource Management System API.

## Setup

Copy `.env.example` to `.env` and set `VITE_API_URL` (normally `http://localhost:5000/api`). Then run:

```bash
npm install
npm run dev
```

Use `npm run build` for a production build and `npm run lint` for code checks.
