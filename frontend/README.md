# Fleetline frontend

React + Vite client for the Fleetline vehicle-management API.

## Setup

Copy `.env.example` to `.env` and set `VITE_API_URL` (normally `http://localhost:5000/api`). Then run:

```bash
npm install
npm run dev
```

Use `npm run build` for a production build and `npm run lint` for code checks.
